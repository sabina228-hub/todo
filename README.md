# 할 일 목록

할 일을 추가하고, 완료 표시하고, 수정·삭제할 수 있는 간단한 할 일 앱입니다.
HTML, CSS, 순수 JavaScript로만 만들었습니다.

## 실행 방법

`index.html`을 더블클릭해 브라우저에서 엽니다. 설치나 서버가 필요 없습니다.

## 기능

- **추가**: 입력칸에 적고 Enter 또는 "추가"를 누릅니다. 새 할 일은 맨 위에 붙고, 빈 내용은 추가되지 않습니다. (최대 100자)
- **완료 표시**: 체크박스나 글자를 누르면 완료/취소됩니다. 완료한 일에는 취소선이 그어집니다.
- **수정**: "수정"을 누르면 입력칸으로 바뀝니다. Enter를 누르거나 다른 곳을 누르면 저장, Esc를 누르면 취소입니다. 내용을 다 지우고 저장하면 원래 내용이 그대로 남습니다.
- **삭제**: "삭제"를 누르면 바로 지워집니다. "완료한 일 삭제"는 한 번 확인한 뒤 완료한 일을 한꺼번에 지웁니다.
- **필터**: 전체 / 진행 중 / 완료 중에서 골라 봅니다.
- **남은 개수**: 목록 아래에 아직 끝내지 않은 할 일 개수가 나옵니다.

## 데이터 저장

브라우저의 localStorage에 `todo-list:v1` 키로 저장합니다. 새로고침하거나 브라우저를 다시 열어도 목록이 남아 있습니다.
그 브라우저에만 저장되므로 다른 브라우저나 기기와는 공유되지 않습니다. 필터 선택은 저장하지 않아서, 다시 열면 항상 "전체"로 시작합니다.

## 파일

- `index.html`: 화면 구조
- `style.css`: 디자인
- `app.js`: 동작과 저장
